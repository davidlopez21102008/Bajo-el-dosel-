Bajo el Dosel - Videojuego de Consola en Python

Descripción del Proyecto

Bajo el Dosel es un videojuego interactivo desarrollado para ejecutarse completamente en la terminal o consola de comandos. Ambientado en un contexto histórico de conflicto y resistencia, el jugador asume el rol de Mateo, quien se une a una columna guerrillera liderada por el Comandante Ernesto.

A lo largo de la historia, el jugador debe tomar decisiones tácticas y éticas en situaciones de emboscada, infiltración y sigilo urbano/rural, administrando sus recursos e inventario hasta tomar la decisión crucial sobre a quién entregar su lealtad en el desenlace de la historia.

Características Técnicas
Consola pura: Diseñado sin librerías externas ni interfaces gráficas.
Paradigma POO: Implementación de Clases, Herencia, Polimorfismo y Encapsulamiento.
Control de Errores: Manejo de excepciones mediante bloques try-except para garantizar una navegación fluida e interactiva.
Funcionalidades avanzadas: Uso de expresiones lambda y alcance de variables local/global (LEGB).
Instrucciones de Ejecución
Requisitos Previos
Tener instalado Python 3.x en el sistema. No se requiere la instalación de librerías adicionales mediante pip.
Pasos para Ejecutar el Juego
Descargar / Clonar el repositorio:
Asegúrate de guardar el archivo de código fuente (por ejemplo, main.py) en tu equipo.
Abrir la Consola o Terminal:
Windows: Abre Símbolo del sistema (cmd) o PowerShell.
macOS / Linux: Abre la Terminal.
Navegar hasta la carpeta del proyecto:
Utiliza el comando cd para situarte en el directorio donde guardaste el archivo del juego:

cd ruta/de/la/carpeta

Ejecutar el programa:
Escribe el siguiente comando y presiona Enter:
En Windows:
python main.py
En macOS / Linux:
python3 main.py

Estructura del Juego

Menú Principal: Nueva Partida, Cargar/Continuar, Opciones y Créditos.
Configuración Inicial: Selección de Dificultad (Fácil, Normal, Difícil) y Tutorial de Mecánicas.
Nivel 2 (Frente Clandestino): Emboscada en la ruta y gestión de herramientas tácticas.
Nivel 3 (Voces en el Pueblo): Infiltración y dilemas morales en terreno hostil.
Nivel Final (Cenizas y Memoria): Elección entre la Opción A (Cubrir la retirada) o la Opción B (El retorno a la tierra), cada una desencadenando un final distinto.
